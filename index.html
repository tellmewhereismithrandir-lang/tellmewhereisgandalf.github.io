About me

Genuine curiosity drives everything I do

I came to software through game development — I wanted to build worlds, and that meant learning to code. What started as a hobby turned into a genuine passion for how software is built and, just as importantly, how it breaks.

Today I focus on QA automation and Python scripting, helping make sure the things people build actually work the way they're supposed to. I care about doing honest, thorough work.

When I'm not at the keyboard I'm usually thinking about philosophy or physics — the kind of questions that don't have easy answers.
